# 06 · 炉式多方块计划

## 1. 结构职责

炉承担高温固体料层、耐火炉膛、气固反应、熔融浴和炉渣/主熔体/炉气多出口。煅烧炉、焙烧炉、竖炉、高炉、熔炼炉、电弧炉与玻璃窑是同一模板的配置。

炉是第四种必要拓扑，但不意味着所有金属线一次进入首发。

## 2. 几何与状态

- 底面 3×3～7×7，高 3～12，可形成高瘦料柱或矮宽熔池。
- 顶部固体进料/炉气，侧面燃烧器/热风/电极/喷吹，底部固体或分层熔体出口。
- 状态域：固体料层、主熔体、炉渣、副产炉气；按配方启用，避免无谓成本。
- 复用共用结构框架，但使用独立炉况状态机，不调用水相反应器冒充。

## 3. 内部件与模式

| 组合 | 模式 |
|---|---|
| 炉篦＋料柱＋热风 | 煅烧、竖炉、直接还原 |
| 炉膛＋燃烧器 | 焙烧、烧结、高温分解 |
| 熔池炉床＋分层出口 | 金属、炉渣、玻璃熔制 |
| 电极＋熔池 | 电热熔炼、电弧/熔盐过程 |
| 密闭炉膛＋冷凝 | 锌、镁等挥发路线 |
| 喷吹口＋熔池 | 氧化/还原精炼 |

回转表现未来可用 Create contraption，但不形成新模板，也不作为首版前置。

## 4. 过程抽象

- 固体热处理：温度、气氛、停留时间和料层决定转化与欠烧。
- 气固反应：O₂、CO、H₂、Cl₂等作为受控进料；火法红氧属于配方层。
- 熔融：达到熔点并支付潜热后进入熔体；主熔体和炉渣按层分别抽出。
- 能量：燃料、热风、Blaze Burner、FE 电极和废热回收进入统一 J 账本。

## 5. 代表工艺

首批：石灰石煅烧、重碱煅烧、氢氧化铝煅烧、硫化矿焙烧、玻璃/水玻璃。

扩展：铁、铜、铅、锌、镍、锡、镁、钛、铬、锰和硅的典型火法段；铝熔盐电解不再永久排除，但必须等熔体与电解能力成熟。

## 6. 玩法差异

- 玩家控制温度、气氛、料层、燃料/热风、熔剂和排渣。
- 欠温产生生料，过热/错误气氛导致结瘤或副产物，炉渣不排会降低有效熔池。
- 炉气和废热可回到硫酸、索尔维、发电与换热线，形成跨厂闭环。

## 7. 施工顺序

1. 通用炉壳、耐火材料、固体和炉气库存。
2. 石灰、重碱、氢氧化铝三条煅烧线。
3. 气氛、料柱、焙烧和热回收。
4. 熔融浴、炉渣分层，以玻璃或一种金属作示范。
5. 按产品用途逐条加入冶金产业。
6. 最后考虑动态回转表现。

## 8. 完成标准

一个 `furnace_controller` 能通过配置完成煅烧、焙烧和熔融浴；炉气、固体、主熔体和炉渣守恒，且世界内可诊断欠烧、气氛错误与排渣问题。
