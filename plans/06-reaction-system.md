# 06 · 反应引擎设计（Create 架构版）

> 关联：[03-substance-model.md](03-substance-model.md)（釜内流股）、[05-mechanics.md](05-mechanics.md)（M5 核心机制）、[07-reaction-catalog.md](07-reaction-catalog.md)（52 条配方）。
> **变化**：配方层复用 Create ProcessingRecipe 管线（白拿 JEI/datagen/KubeJS）；釜内执行端为自研流股模拟（进度/中间态/温度/压力/催化）。

## 1. 两级结构

```
┌─ 配方层（复用 Create ProcessingRecipe 管线）──────────────┐
│  RecipeType: chemical_reaction（自定义，ProcessingRecipe 派生）│
│  字段：item+fluid 输入 / fluid+item 输出（含概率副产）/       │
│        HeatCondition 门槛 / processingTime / 催化剂物品 /     │
│        自定义字段：压力下限、温度窗口、浓度要求、ΔH           │
│  生态红利：JEI 展示、datagen、ponder、KubeJS-Create 脚本加反应 │
├─ 执行层（自研：釜内流股模拟）─────────────────────────────┤
│  釜内容器：多物种流股共存（匠魂熔炼炉式多流体罐 + 状态）        │
│  模拟：进度 0→100%、分步中间态、温度/压力演化、催化寿命、       │
│       平衡简化（转化率上限/方向切换）、事故检测               │
└──────────────────────────────────────────────────────────┘
```

## 2. 配方数据结构（概念层）

```
chemical_reaction {
  inputs:      [ {fluid: 盐水, amount}, {item: 石灰石, count}, ... ]   // 也可气体流体
  outputs:     [ {fluid: 烧碱液, amount}, {item: 纯碱, chance}, ... ]   // 概率副产同 ProcessingRecipe
  heat:        HEATED | SUPERHEATED | NONE          // Create HeatCondition
  pressure:    { min: 0.1MPa, max: 常压 }            // 自定义（自研）
  temperature: { min: 30°C, max: 60°C }              // 自定义（显示用，热级校验为准）
  catalyst:    { item: 五氧化二钒, durabilityPerUse: 100 }   // 可选
  processingTime: 300  // tick，釜容量放大时吞吐等比放大
  deltaHeat:   +1200   // ΔH：放热为正（釜温升）/ 吸热为负（需供热）
  intermediates: [NaHCO₃]  // 分步反应的中间物种（可选，用于多段配方链）
  requires:    { seal: SEALED }  // 密封等级要求（常压/密封/高压）
  balancing:   { maxConversion: 0.8, reversible: false }  // 平衡简化
}
```

全部字段 JSON 化（KubeJS 可写）；催化剂与密封/压力为自研扩展字段（ProcessingRecipe 的 `extraConditions` 思路）。

## 3. 釜内执行模拟（核心算法，概念层）

每低频 tick（10 tick）执行：

```
1. 匹配：釜内容器流股集合 vs 已登记配方（控制面板选定，最多同时 1 个主配方 + 0..2 个副配方）
2. 校验：热级 ≥ 门槛（Blaze Burner/夹套状态）、压力 ∈ 窗口、密封等级、催化剂在位、浓度下限
3. 进度：progress += baseRate × 温度系数 × 搅拌系数 × 规模系数
   - 温度系数：窗口内 1.0，低于下限衰减（0.5/0.25…），高于上限触发危险检查
   - 搅拌系数：转速 0 时 0.3（传质差），满速 1.0；塔式无搅拌用喷淋/鼓泡代替
   - 规模系数：釜容量（方块数）与配方基准量的比值（大釜一次处理更多）
4. 中间态：progress 过 50% 且配方声明 intermediates → 先产出中间物种（如 NaHCO₃ 浆料）再继续
5. 结算：progress ≥ 100% → 消耗输入、产出输出；催化剂扣耐久；ΔH 作用于温度
6. 温度演化：T += ΔH×当次转化量 - 散热（环境/夹套/冷却塔）；放热大则升温→加速（正反馈=热失控风险）
7. 压力演化：密封容器内 气相量×T → P（线性近似）；超限→泄压阀/爆炸
8. 事故检测：禁忌组合检查（如浓硫酸+水并存）、超温分解、腐蚀（无内衬）
```

**设计要点**：
- **放热=玩法**：ΔH 让温度爬升，玩家必须配冷却（夹套/换热器/冷却塔），否则热失控——「反应条件」不是配方字段，而是玩家要搭建的工程；
- **转化率上限**（如合成氨 15–20%）= 强制「循环未反应气体」的闭环教学；
- **分步中间态** = 教学（索尔维碳化的 NaHCO₃ 沉淀是主产物步骤，不是中间态；中间态用于接触法 SO₃、氨氧化 NO→NO₂ 等）。

## 4. 平衡简化（三档）

| 档 | 规则 | 例子 |
|----|------|------|
| 完全正向 | 消耗完输入即完成 | 中和、煅烧 |
| 转化率上限 | 配方达到 maxConversion 后停止消耗（需循环分离） | 合成氨（0.15–0.2）、接触法 SO₂→SO₃（0.95） |
| 条件切换方向 | 温度/压力窗口决定正逆方向 | CO₂ 吸收/解吸、氨水蒸馏 |

不做真实平衡常数计算；每档都是查表+阈值，可表达、可调试、可教学。

## 5. 催化

- 催化剂 = **物品**（V₂O₅ 触媒、铁触媒、铂网），放入釜内 S07 催化剂托盘；
- 效果：降低热级门槛（如接触法 SEETHING→KINDLED）或提高转化率上限；
- 寿命：耐久值，每完成一批配方扣减；可用漏斗/机械臂自动更换（物品物流白拿）。

## 6. 禁忌组合与事故（M10 细化）

| 禁忌 | 判定 | 事故 |
|------|------|------|
| 浓硫酸 + 水 | 釜内并存 | 剧烈放热+飞溅（容器温度瞬升、压力骤升） |
| 氯气 + 氢气（无点火） | 并存+达到燃点 | 爆鸣（小范围爆炸） |
| 次氯酸盐 + 酸 | 并存 | 放出氯气（毒气泄漏） |
| 碱金属?（不引入） | — | — |

判定在釜内流股混合时检查（配方制之外的安全网）；泄漏的毒气进入净化塔可处理（T3 后）；事故强度可配置（仅损物料/破坏结构）。

## 7. 与 Create 配方的边界

- **简单处理**（不涉及温度/压力/中间态）：用 Create 原生配方就行（Mixing/Compacting/Filling），如 盐+水→盐水 用 Mixing、矿物粉碎用 Crushing——**这些不进釜**，玩家用 Create 的搅拌机/粉碎机即可，釜只做"化学反应"；
- **化学反应**（条件/进度/放热）：必须进釜（或电解槽等专用块）；
- 这样釜数量需求下降，Create 原生机器承担前处理，分工清晰（呼应 D6 机器分工，但口径更细）。

## 8. 配方集规模

52 条反应（见 07-reaction-catalog），按模块分组（原料/酸/氯碱/索尔维/合成氨/铝/废料/物理分离），其中：
- ~18 条为 Create 原生配方（溶解/粉碎/结晶等物理过程）；
- ~34 条为 chemical_reaction（釜内反应）。
