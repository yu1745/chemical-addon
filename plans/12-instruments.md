## 0. 一句话结论

**连续贴面仪表封顶 7 台**（温度计/压力表已实现 + 波美计/pH 计/浊度计/电导率计/液位计）**+ 消耗性试纸族**，不再多。每台仪表 = 读数函数 + 量程 + 分箱 + 阈值行为，照 S03 模式复制，边际成本递减。

## 1. 设计原则

1. **测量诚实性**（03 §6）：玩家仪器只读**物理间接量**——pH、密度、浊度、电导率、温度、压力、液位、颜色。引擎内部知识（SI/speciation/成分百分比）永远不可见，仅 `Chemistry.ASSAY` dev 化验模式解锁。
2. **机器不替玩家化验**：无纯度阈值判定、无「物种识别」输出——「是什么」永远是化学活（试纸/焰色/投料行为）；机器只回答「多少/到没到」。
3. **终点类型学（仪器封顶的依据）**：无机化工的「反应完了没」只有四类信号物理量，每类恰好一台化学仪表：
   | 终点类型 | 典型场合 | 仪表 |
   |---|---|---|
   | 化学势（滴定型） | 中和、碳化、吸收 | pH 计 |
   | 质量浓度（浓缩型） | 酸碱浓度、盐水饱和 | 波美计 |
   | 相态（沉淀型） | 除杂「刚不再浑」、初浑报警 | 浊度计 |
   | 离子强度（洗涤/纯水型） | 洗滤饼、去离子水验收 | 电导率计 |
   新产线先问「终点属于哪一类」，四类里选，**不再新增仪表类型**。
4. **世界内交互**（AGENTS 基调）：读数=贴面指针/刻度 + 护目镜行；阈值=ValueSettings 世界内滚动调值；零 GUI。

## 3. 红石联动（仪表族铁律，统一双输出）

S02/S03 已实现的模式固化为族规范，所有新表照抄：

1. **比较器模拟量 0–15**：量程内分箱（每表分箱见表 2.1），给红石算术电路用。
2. **阈值模式（自动化主力）**：ValueSettingsBehaviour 世界内滚动设阈值 + 右键切「高于触发/低于触发」，满足时强充能 15。典型控制语义全是事件触发：pH ≥ 7 停投酸、波美 ≥ 25 停加热、初浑 → 断料、电导 ≤ 阈值 → 洗涤完成。
3. **pH 映射注记**：pH 本身是对数标尺，线性分箱 1 级 = 1 pH 语义天然正确；强酸强碱等当点附近一滴跳 3–5 个 pH，直接表现为红石跳变——窗口检测（「先过 4 再过 7」=等当点）用原版比较器即可搭。
4. **为何阈值模式是主力**：等当点跳变快于模拟量采样周期，事件语义（cross 触发）比轮询 16 级稳；且与 S12–S15 节拍控制链（04-machines 注记）衔接：测量（仪表族）→ 决策（原版红石 + Create 阈值开关/红石链接）→ 执行（Smart Fluid Pipe/泵/Clutch），零 GUI。

## 5. 引擎依赖（读数函数的实现前置）

- **Kw 常数解封（U17 已实现，pH 计唯一前置）**：`Chemistry.KW = 1e-14`。酸性侧直读 H⁺；碱性侧 [H⁺] = Kw/[OH⁻]；纯水/中性盐（求解器中和定点两离子皆 0）pH 7 免费获得——三例穷尽（`Analyte.ph`）。**实现决策（2026-08）：Kw 落在读数层常数而非求解器 equilibria 条目**——真实自电离对（1000 mB 中恰好 1 unit H⁺+1 unit OH⁻）会被写回 Ions 域、改变 GCD ratio-tag 身份：釜内已解液与同配比新装桶永远无法合并堆叠，且 1 unit 对除读数外的一切机制不可见。与弱电解质通道（氨水电离）的中和交互 JUnit 复核通过（AnalyteTest：等当点 ±1 mB 跳 pH 11↔7↔3）。
- **波美换算（U17 已实现）**：浓度（Σ溶解 units / 水 units）→ °Bé 的**声明式**线性换算，锚点=曲线饱和盐水（rock_salt 36 g/100g → 每 formula 拆 2 离子单位 → dissolved/water = 0.72 → 30°Bé）——不分物种，同浓度不同盐波美几乎一样是特性不是缺陷（诚实性：它告诉你溶了多少，不告诉你溶了什么）。分子溶质（氨/糖类）同样计入。
- **浊度/电导**：`Suspended` 域 / 离子域直读，零引擎改动（浊度边界 1%/5%/20%；沉底床不计入）。
- **护目镜行（U17 已实现）**：各表读数进 HUD；SI/speciation 行已降级 `ChemicalAddon.ASSAY_ON`（dev 化验，玩家常态无 SI）。

## 6. 与机器的关系（仪表不是装饰）

- **M08 终点结晶器**（✅ U17 落地，`CrystallizerControllerBlockEntity`——反应釜子类）：物理量设定点（°Bé 世界内滚动，步进 2 与 S04 对齐）+ 终点红石事件（强充能 15 + 比较器 °Bé 进度）+ 排汽冷凝回收（`RulesEngine` 通气量累加 → 内置馏出水产罐，被动推向相邻非容器流体消费方）。它就是「读同一物理量的执行器」，不另起一套魔法判定；到达设定点切热（`heatTarget` 覆写回环境温度）。「只析 A 不析 B」由设定点低于 B 的饱和线挣得——设定点挣取三路径（校准运行/手册推算/试纸质检）。
- **过滤机洗水模式**（U16.5）：置换洗涤洗穿滤饼，S18 读滤液电导=洗涤终点闭环。
- **设定点挣取三路径**（校准运行/手册推算/试纸质检）见 plans/11 U17 行；**精度来源是化学不是机器**：投种后 A 钉在饱和线上 → 密度爬升全归因 B 富集。
