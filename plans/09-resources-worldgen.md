## 1. 新增矿物（5 种，世界生成）

| 矿物 | 生成规则 | 用途 | 阶段 |
|------|---------|------|------|
| 岩盐（盐岩层） | 地下盐丘/盐层，湖畔/沙漠地下常见 | 盐水→氯碱、索尔维 | T0 |
| 石灰石（岩层） | 山脉/平原地下大矿脉（成层状） | 石灰窑→生石灰+CO₂ | T0 |
| 硫磺矿 | 火山生物群系/地狱，地表晶体+矿脉 | 硫酸厂原料 | T1 |
| 铝土矿 | 温带/红土丘陵，中等深度 | 拜耳法→氧化铝（T4 耐火件；熔融电解铝 F4 预留后续版本） | T3 |
| 磷矿 | 河床/沉积层 | 湿法磷酸、磷肥 | T3 |

- 均可用 Create 开采链（钻头/粉碎→Create 粉碎机碾磨——**矿物粉处理直接复用 Create 加工链**）；
- 生成受 FTB Chunks 领地保护约束（服务端已有联动，破坏校验白拿）。

## 3. 资源链概览（从矿石到产品的完整拓扑）

```
岩盐 ─→ 盐水 ─┬→ 氯碱：NaOH + Cl₂ + H₂ ─→ HCl / 漂白液
              └→ 索尔维：氨盐水 → NaHCO₃ → 纯碱（NH₃/CO₂ 循环）
石灰石 ─→ CaO + CO₂ ─┬→ 石灰乳：中和、氨回收、脱硫
                     └→ CO₂ → 碳化、尿素
硫磺 ─→ SO₂ ─→ SO₃ ─→ H₂SO₄ ─→ 磷肥、酸洗、硫酸铵
水+煤 ─→ 水煤气(H₂+CO) ─→ H₂ → 合成氨（+N₂）
铝土矿+NaOH ─→ NaAlO₂ ─→ Al(OH)₃ ─→ Al₂O₃ ─→ Al
磷矿+H₂SO₄ ─→ H₃PO₄ + 磷石膏（废料处理案例）
```

## 4. 副产物去向表（闭环设计依据）

| 副产物 | 产生 | 去向 |
|--------|------|------|
| CaCl₂ 废液 | 索尔维氨回收 | 蒸发结晶→CaCl₂ 固体（干燥剂/融雪剂）或处理 |
| 磷石膏 | 湿法磷酸 | 滤渣→建材块（T4） |
| 未反应气 | 合成氨 | 循环回高压釜（转化率上限机制） |
| 稀硫酸 | 吸收塔尾气 | 浓缩回用/中和 |
| 滤饼 | 过滤机 | 回溶/建材/填埋 |
