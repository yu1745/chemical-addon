### 2.2 开发主线：以索尔维制碱法为 spine（开发策略）

> **原则**：开发顺序 = 索尔维制碱法所需方块/能力的前置依赖顺序。每个开发单元（方块/机制/引擎能力）交付时都要能在索尔维流程中跑通并被主流程验证——M3+ 不会散成「随手挑一块做」，每个单元都有明确的上下游目标。

#### 索尔维硬件清单（自研）

| 类别 | 器件 | 数量 |
|------|------|------|
| 化工装置（必研） | 石灰窑（M16 竖窑，供 CO₂+生石灰）、吸收塔（M05 吸氨）、碳化釜（M02，**连续流模式**）、过滤机（M10，可选 M06 预浓缩）、煅烧炉（M16 窑型复用，CO₂ 回收）、蒸氨塔（M04 蒸馏塔）、蒸发结晶器（M08，CaCl₂ 收尾） | **7**（窑共用 1 型则 6） |
| 辅助控制件 | S02 温度计 / S03 压力表 / S04 浓度计 / S11 液位计；S06 化学泵；S12 反应状态接口 / S13 计量投料口 / S14 溢流口 / S15 批次程控器 | **~9–11** |

> 索尔维**无催化步骤**，S07 催化剂托盘暂缓。全套器件类型合计约 **26–28 种**；模板实例合并 + 省略可选件可压到 ~20 种跑通。

#### 与里程碑的映射

| 索尔维步骤 | 需要的开发单元 | 对应 |
|-----------|---------------|------|
| 石灰煅烧 / 重碱煅烧 | 竖窑连续进出料 + 高温热源 + CO₂ 回收 | M3+（M16） |
| 盐水吸氨 | 塔式模板（喷淋/填料）+ 连续吸收 | M3+（M05） |
| 碳化 | **连续流引擎（mode + 停留时间 τ）+ 逆流气液吸收** | 13-flow-modes F2/F3 |
| 过滤 | 过滤机 / 沉淀池 | M2 ✅ 已有 |
| 氨回收（蒸氨） | 蒸馏塔模板（再沸釜 + 塔板 + 冷凝段） | M3+（M04） |
| 副产 CaCl₂ 收尾 | 蒸发结晶器 | M3+（M08） |
| 全流程自动化 | S11–S15 节拍控制件 | 13-flow-modes F1 |

#### 开发节奏建议

1. **先骨架后补全**：M3+ 首批按「竖窑 → 吸收塔 → 蒸馏塔」补塔式/连续装置，让索尔维主链（除碳化连续流外）先能手动跑通；
2. **再上连续流**：F2/F3 落地后碳化塔进稳态，主链闭环自动化；
3. **最后收尾**：CaCl₂ 结晶、换热/冷却、节拍程控打磨，达成 T2 验收「索尔维闭环」并顺带产出零排放样板。
