## 4. 风险清单

| 风险 | 等级 | 缓解 |
|------|------|------|
| Create API 变动（6.0.8 锁定，不追新） | 低 | 锁定版本 |
| 釜内模拟性能（多釜同区块） | 中 | 低频结算+调度器合并 tick（10-multiblock §7） |
| 61 种流体的贴图/模型工作量 | 中 | 程序化生成（颜色+透明度+相态模板），少画手绘 |
| 模板通用性不足（新容器要新结构代码） | 中 | 参数表驱动，控制器注册化（10-multiblock §6） |
| KubeJS 对自定义 RecipeType 支持深度 | 低 | 先保证 datagen+JEI，脚本化作为红利 |
| 与 TFMG/柴油发电机并存（同一服务器） | 低 | 无机主线不重叠；流体 ID 无冲突（前缀隔离） |
| 事故强度平衡（爆炸破坏范围） | 中 | 配置化，默认温和 |
