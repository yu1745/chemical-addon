## 1. 与 Create FluidTank 的分工（先划清边界）

| | Create FluidTank | 自研反应容器模板 |
|--|------------------|------------------|
| 内容物 | 单种 Forge Fluid（SmartFluidTank） | **多物种流股共存**（匠魂熔炼炉式多流体罐 + 反应模拟） |
| 状态 | 无温度/压力/进度 | 温度、压力、反应进度、中间态、浓度、催化 |
| 功能 | 储存/被动锅炉 | 执行化学反应（白名单配方） |
| 复用 | 标准态液体/气体的储存与缓冲 | 一切「会发生化学变化」的地方 |

规则：**运输与储存用 Create 罐；发生反应用自研容器**。玩家心智模型：罐是"仓库"，釜是"反应器"。

## 2. 模板结构规范

### 2.1 组成部分

```
        ┌── 顶盖（密封件，可选排气口/加料口）──┐
        │   内部件：搅拌头 / 塔板 / 喷淋 / 催化剂托盘 │
        │   控制器（一面，无 GUI，状态走护目镜 HUD）       │
  ┌─────┼─────┐  壳体（环壁） 窗口（观察/量具）   │
  │ 端口  │  端口 端口=流体口(液/气)、热接口、   │
  │(旋转口)│       (旋转口=搅拌轴穿过)         │
  └─────┴───┬─┘  底（热源槽位/排渣口）          │
            └── 内衬（耐腐蚀/耐压/保温，可选）    │
```

| 部件 | 方块 | 功能 |
|------|------|------|
| 壳体 | 化工砖/钢壳/合金壳（3 材质） | 结构主体；材质决定基础耐温/耐压 |
| 内衬 | 耐酸衬/耐压衬/保温衬（2–3 种） | 叠加属性：腐蚀耐受、压力上限、隔热 |
| 窗口 | 观察窗 | 透光、显示液位/温度色；可有量具刻度 |
| 端口 | 液体口、气体口、旋转口、热接口（4 种） | 与外部体系对接（见 §3） |
| 控制器 | 釜控制器/塔控制器/池控制器（3 种） | 成型校验、状态机、护目镜 HUD/诊断、红石输出（含 S12 状态接口） |
| 底/顶 | 底板（热源槽位）、顶盖（密封/排汽/加料） | 形状与密封相关 |

### 2.2 成型规则（与 Create 罐同哲学：先搭后激活）

1. 玩家按规格搭好壳体（如 3×3 底 × 高 4 的筒 + 底板 + 顶盖），放入内衬（可选）；
2. 在任意一面（或顶/底）放**控制器**；
3. 控制器右键激活 → 校验：形状合法、壳体材质一致、无缺口、端口未堵 → 成型成功（音效+粒子+结构发光），否则提示缺失/错误位置；
4. 成型后结构为整体：破坏任一部件 → 整体失效（内部流体保留在 NBT，结构重建后可恢复，类似 Create 罐断连）。

尺寸限制（防滥用+性能）：

| 形状 | 底面 | 高度 |
|------|------|------|
| 釜式 | 3×3（圆角壳） | 2–6 |
| 塔式 | 1×1 ~ 3×3 | 3–12 |
| 池式 | 3×3 ~ 7×7 | 1（可 2 层加深） |
| 高压釜 | 3×3（环形壁） | 2–4 |

### 2.3 材质分级（耐温/耐压/耐腐蚀表）

| 材质 | 解锁 | 耐温 | 耐压 | 耐腐蚀 | 说明 |
|------|------|------|------|--------|------|
| 化工砖（陶/砖+涂层） | T1 | ≤200°C | 常压 | 弱酸弱碱 | 入门 |
| 钢壳 | T2 | ≤600°C | 密封 3 MPa | 一般 | 氯碱/硫酸主材 |
| 耐压合金壳+耐压衬 | T3 | ≤1000°C | 高压 20 MPa | 强酸 | 合成氨/拜耳法 |
| 耐酸衬（铅/玻璃衬） | T2 | 同壳体 | 同壳体 | 浓酸/浓碱 | 硫酸/氯碱设备 |

组合规则：**壳体决定基础，内衬叠加属性**（如钢壳+耐压衬 = 高压；钢壳+耐酸衬 = 强酸釜）。属性不足的反应配方直接拒绝执行（提示缺什么）。

## 3. 端口协议（与外部生态的对接点）

| 端口 | 对接 | 说明 |
|------|------|------|
| 液体口 | Forge Fluid（Create 管道/泵直接连接） | 输入/输出标准态流体；釜内自动转流股 |
| 气体口 | Forge Fluid（气体物种，Create 管道） | 气体进出；密封容器内计入压力 |
| 旋转口 | Create 动能网络（KINETIC） | 搅拌头/刮刀轴；转速影响搅拌效率 |
| 热接口 | BoilerHeater.REGISTRY / HeatCondition | 底部热源槽位认 Blaze Burner 等；夹套口接换热器/蒸汽 |
| 电口 | ForgeCapabilities.ENERGY（createaddition 电网） | 电解槽/电热器专用 |
| 物品口 | IItemHandler（漏斗/传送带/机械臂） | 固体进出：加料（重碱、石灰石）、出料（滤饼、纯碱）、催化剂托盘 |
| 数据口 | 红石/阈值开关/显示屏 | 状态读取、报警、自动启停；节拍控制的传感器/程控器见 [04-machines.md](04-machines.md) §5 的 S11–S15 |

## 4. 内部状态可视化（自绘，不依赖流体渲染）

- **液位**：窗口处按流体总量画液面高度（多物种按体积叠加，分层色带）；
- **温度色**：热=红→白渐变，冷=蓝（可开关）；
- **气相**：顶部雾状粒子（浓度高时明显）；
- **沉淀**：底部固相层（浆料/结晶）；
- **进度**：护目镜 HUD 显示反应进度条；运行中壳体有微光/流动纹理；
- **仪表口**：S02–S04 仪表方块可贴窗口/壳体读取。

## 5. 故障与安全（与机制 M10 联动）

| 故障 | 触发 | 表现 | 预防 |
|------|------|------|------|
| 超压 | 密封容器内气体量×温度超限 | 先漏气（顶盖缝隙喷气粒子）→ 泄压阀排放 → 未装阀则**爆炸**（破坏结构，范围按容量） | S05 泄压阀、压力表报警、配方限压 |
| 热失控 | 放热反应 + 冷却不足 → 温度超限 | 温度飙升动画 + 反应加速（正反馈）→ 超温分解/爆炸 | 冷却接口、换热器、配方温度窗口 |
| 禁忌混合 | 釜内出现禁忌组合（浓硫酸+水等） | 剧烈反应事故（产热+产气+腐蚀） | 规则引擎自动检测（安全网，06 §6）、手册警告、仪表报警 |
| 腐蚀 | 强腐蚀流体 + 无耐酸内衬 | 内衬/壳体耐久下降 → 漏液 | 材质分级表提示 |
| 堵塞 | 浆料固含量过高 + 无搅拌/沉淀池 | 出料口堵塞，泵空转 | 过滤机、搅拌、浓度控制 |

## 6. 模板的扩展方式（后续自研多方块的范本）

新容器 = 复制模板参数表，不写新结构逻辑：

1. 选形状/尺寸/密封组合 → 注册新控制器（复用同一套结构校验与状态机）；
2. 挂内部件（已有：搅拌/塔板/喷淋/刮刀/催化剂盘；新需求新做 1 个内部件方块即可）；
3. 注册配方集（哪个 RecipeType 在此容器可执行）+ 默认配色/贴图。

已规划实例：M02 反应釜（T1 首个，教学范本）→ M05 吸收塔、M07 中和池（T1/T2 同模板）→ M04 蒸馏塔、M08 蒸发结晶器、M15 净化塔（T2/T3 塔式）→ M03 高压釜（T3 环形+耐压）。

## 7. 性能与存档

- 釜按**低频结算**：配方进度 10 tick 一跳、温度松弛 5 tick、压力重算 20 tick；大釜（>64 方块）自动降频；
- 结构状态（部件清单、内衬、密封等级）与内容（流股列表、进度、温度、压力）全部进 NBT；
- 区块卸载/存档恢复：容器作为整体序列化，重建时一次反序列化（避免逐方块恢复）；
- 同 chunk 内多釜：共享一个容器结算调度器（合并 tick，限制每 tick 容器数）。
