## 1. 一句话定位

**一个以「多方块化工容器 + 闭路化学循环」为核心的 Create 附属**：玩家用 Create 的管道、传送带、旋转动力与热源搭建化工厂，把矿石、水、空气变成酸碱盐和金属，再把副产物与废料回收进循环，最终建成零排放的化工帝国。

## 2. 目标玩家

- Create 玩家（旋转/传动带/锅炉已有认知，直接迁移）；
- 喜欢「建产线、调参数、跑闭环」的工厂玩家（GT/MEK 经验者）；
- 化工厂美学爱好者（管廊、塔器、储罐群）。

**不适配**：一键合成党、纯冒险玩家。

## 3. 核心玩法循环（5 步）

```
① 勘探选料  →  ② 搭建立方  →  ③ 铺设管线  →  ④ 调参运行  →  ⑤ 闭环与放大
  找矿点       搭釜体（模板）    通流体/动力/热     物理装置调参     副产物回收，
  采盐/石灰石   选壳体材质内衬    传送带运固体      配方，调温调压    试剂循环，
  烧硫磺        激活结构         红石接线          监视进度          扩建塔器
```

## 4. 成就感支柱

| 支柱 | 玩家体验 | 对应内容 |
|------|---------|---------|
| **闭环** | 氨/CO₂ 循环利用，废液变产品，零排放 | 索尔维制碱、尾气净化塔、中和池 |
| **工程感** | 釜塔池管廊林立的化工厂全景 | 釜体模板实例化、管廊、传送带 |
| **参数掌控** | 温度压力浓度一手调，反应「驯服」 | 物理装置（热源/冷却/搅拌）、仪表、泄压阀 |
| **事故管理** | 跑温、超压、误混的紧张与抢救 | 危险机制（M10）、混液炸管 |
| **自动化** | 全流程无人值守（Create 红石+物流） | 阈值开关、漏斗、机械臂、转速控制器 |

## 5. 反设计清单

1. **不做无限合成树**：52 条反应全部有工业逻辑；
2. **不做魔法化学**：反应式配平、条件合理（适度简化）；
3. **不强制数学**：表盘显示温度/压力/浓度，直觉判断（热好还是冷好）要成立；
4. **不重复 Create**：简单物理过程（溶解/粉碎/结晶）直接用 Create 搅拌机/粉碎机，釜只做化学反应；
5. **不做「任意混合即反应」**：白名单配方制 + 禁忌组合安全网；
6. **不做石油/柴油/精馏**（TFMG/柴油发电机已做）：主攻无机化工（D15）。

## 6. 与 Create 生态的关系

| 生态能力 | 化学附属的用法 |
|---------|---------------|
| 旋转动力 | 搅拌头、过滤机、离心机、压缩机的驱动（水车→蒸汽机→创想电动机） |

| 红石/转速控制器/阈值开关 | 自动化控制、报警联锁 |
| 电网（创想附加） | 电解槽/电热器供电 |
| JEI/KubeJS/datagen/ponder | 配方展示、脚本扩展、教程 |

## 7. 玩家旅程示例（Create 视角）

> 你用风车带动第一台搅拌头，在 3×3×2 的砖釜里把硫磺烧成的 SO₂ 吸收成稀硫酸——这是你的第一座「化工厂」。
> T2 锅炉蒸汽机的轰鸣声中，电解槽吐出氯气，吸收塔里氢氯合成盐酸；你把副产品氢气接回 Blaze Burner 当燃料，能源自给了一小半。
> 索尔维塔区建起来了：盐水吸氨、碳化沉淀、重碱煅烧、氨回收，传送带上纯碱源源不断，氨在管廊里循环——你盯着流速表，意识到自己在开一座真正的化工厂。
> T3 高压釜里合成氨，回转窑转动着煅烧铝土。T4 尾气净化塔亮起绿灯：零排放。
