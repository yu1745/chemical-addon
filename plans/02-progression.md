# 02 · 进度线设计（T0–T4，Create 架构版）

> 文档状态：**current**（阶段线 T0–T4，含批式/连续流落点，见 13-flow-modes）

> 关联：04-machines（机器）、05-mechanics（机制）、06-reaction-system（反应引擎）。
> **变化**：动力线接 Create 原生（手摇→水车/风车→蒸汽机→创想电动机）；热源线接 Blaze Burner/锅炉/液体烈焰人；阶段解锁以「闭环」为通关凭证。

|------|------|--------|--------|---------|--------|
| T0 | 原始化工 | 溶解、蒸发 | 手持工具+锅/桶：磨盐、溶盐水、烧石灰（借熔炉） | 手摇 | 制成第一份盐与石灰 |
| T1 | 酸碱入门 | 温度（HeatCondition）、沉淀、过滤 | **釜体模板首实例 M02**、搅拌头、M06 沉淀池、M10 过滤机、S 系列仪表 | 水车/风车 | 制稀硫酸+石灰乳，完成一次中和（批式节拍入门，见 13-flow-modes） |

> **开发主线（策略）**：以**索尔维制碱法为开发 spine**——M3+ 每个开发单元按「索尔维所需方块/能力」排序，交付即在主流程中验证，避免开发散乱。硬件清单与里程碑映射见 [11-content-scope.md §2.2](11-content-scope.md)。

## T0 · 原始化工（无多方块）

- **内容**：盐岩磨粉→桶溶盐水；石灰石借原版熔炉烧成生石灰（放走 CO₂，埋 T2 回收伏笔）；锅蒸发盐水得盐（结晶初体验）。
- **教学**：手册第一章「物质有状态」；Blaze Burner 首次接触（烧制）。

## T1 · 酸碱入门（第一座自研多方块）

- **内容**：
  - 搭 M02 反应釜（3×3×2 釜式，化工砖）——**新手教程即范本教学**（ponder 场景逐步指导成型）；
  - 硫磺矿焚烧（Blaze Burner 热级 1–2）→ SO₂ → 釜内吸收成稀硫酸（或 M05 吸收塔提前解锁）；
  - 石灰乳制备、石膏沉淀（M06 沉淀池 + M10 过滤机出滤饼 item 上传送带）；
  - 中和池 M07 首次中和（石灰乳+稀硫酸→石膏+水，放热→需冷却接口）。
- **机制**：温度（HeatCondition：HEATED/SUPERHEATED 门槛）、沉淀（浆料流股固含量）、过滤（浆料→滤液+滤饼 item）。
- **卡点**：盐酸被锁（Cl₂ 要 T2 电解）→ 引导玩家建电解槽；浓硫酸+水禁忌教学关（故意让玩家踩一次小坑）。

## T2 · 工业化学（旗舰阶段）

- **内容**：
  1. **氯碱**：M09 电解槽（FE，创想电网：电动机+发电机或电池仓）→ 烧碱+Cl₂+H₂；H₂+Cl₂ 在 M05 吸收塔合成盐酸；Cl₂+烧碱→漂白液；
  2. **硫酸厂（接触法）**：硫磺焚烧→SO₂→（M13 换热器预热）→釜内 V₂O₅ 催化氧化→SO₃→吸收塔制浓硫酸/发烟硫酸；
  3. **索尔维制碱（旗舰闭环）**：吸收塔制氨盐水 → 釜碳化（NaHCO₃ 沉淀，中间态教学）→ 过滤出重碱 → 煅烧（M16 竖窑或回转窑）得纯碱+CO₂ 回收 → 氯化铵废液+石灰乳回收氨 → 循环。CO₂ 来源=石灰窑，石灰乳副产品 CaCl₂ 废液进蒸发结晶。
- **动力**：锅炉+蒸汽机（Create 原生）或创想电动机（FE）。
- **里程碑**：索尔维闭环跑通（连续流模式教学，见 13-flow-modes）；手册成就「氨循环」。

## T3 · 高压化工

- **内容**：
  1. **合成氨**：M12 压缩机 + M03 高压釜（耐压合金壳+耐压衬，20 MPa），N₂（空气经蒸馏塔 M04 分离）+ H₂（水煤气或电解水）→ 哈伯法（SEETHING+高压），转化率 15–20% → **未反应气体循环回釜**（深刻闭环教学）；
  2. **硝酸**：氨氧化（回转窑/高温釜）→ NO → NO₂ → 吸收塔制硝酸；
  3. **化肥**：硫酸铵/硝酸铵（釜）+ 蒸发结晶出晶体；
  4. **拜耳法**：铝土矿+烧碱高压溶出（高压釜）→ 晶种分解沉淀（池式+搅拌）→ 氢氧化铝 → 回转窑煅烧 → 氧化铝。
- **里程碑**：合成氨闭环（未反应气连续循环，见 13-flow-modes）；拜耳法产氧化铝（熔融电解铝 F4 为后续版本预留）。

## T4 · 零排放工厂

- **内容**：M15 尾气净化塔（毒气吸收：SO₂/Cl₂/NO₂，Fan 引风）；废酸废碱全中和；冷却水全换热回收；滤渣/磷石膏集中制建材；全厂状态面板「回收率 100%」。
- **终局**：巨型化竞赛（池式 7×7、塔式高 12、高压釜群组），产能拉满。

## 跨阶段主线（不变，强化）

1. **CO₂ 的救赎**：T0 放走 → T2 索尔维回收 → T3 尿素 → T4 全回收。
2. **氨的旅程**：T2 索尔维氨循环 → T3 合成氨 → 化肥 → 制冷冷媒。
3. **水的角色**：T1 冷却水直排 → T2 冷却塔 → T4 换热回收。
4. **废料的逆袭**：石膏/磷石膏/氯化钙全部找到去处。
