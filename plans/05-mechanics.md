# 05 · 机制清单（Create 架构版，10 种）

> 文档状态：**current**（机制清单；M4/M5 已 v2 对齐）

> 每个机制给出：定义 / 玩家交互 / 边界与简化 / **Create 对接点** / 可表达性一句。
> 关联：[03-substance-model.md](03-substance-model.md)（流股）、[06-reaction-system.md](06-reaction-system.md)（反应）、[04-machines.md](04-machines.md)（载体）。

## M1 温度与传热

- **定义**：容器温度（°C 连续整数）；热源供热、放热反应升温、冷却带走热；温度决定相态与反应可行性。
- **玩家交互**：釜底放 Blaze Burner（看火焰状态判断热级）、接夹套（换热器/蒸汽）、配冷却塔；面板显示温度与目标窗口。
- **边界**：不做连续热传导场——容器视为均质（内部搅拌保证）；温度松弛低频结算。
- **Create 对接**：热级 = HeatLevel（NONE/SMOULDERING/FADING/KINDLED/SEETHING）；配方门槛 = HeatCondition（HEATED/SUPERHEATED）；热源注册进 `BoilerHeater.REGISTRY`（Blaze Burner、锅炉、创想液体烈焰人直接可用）；夹套换热走自研流股温度交换。
- **可表达**：温度是釜内流股共享标量，完全可表达。

## M2 压力与密封

- **定义**：密封容器内气体量×温度 → 压力（简化线性近似）；密封等级（常压/密封/高压）定上限；超压→泄压→爆炸。
- **玩家交互**：装泄压阀、看压力表、配方要求高压（合成氨）→ 必须用高压釜+压缩机。
- **边界**：不做真实气体定律；压力只在密封容器内计算；爆炸范围与容量挂钩。
- **Create 对接**：无现成压力概念，全部自研（釜内流股字段）；爆炸可复用通用爆炸 API 与破坏保护（FTB Chunks 联动已在服）。
- **可表达**：标量字段+阈值事件，可表达。

## M3 相态与相变

- **定义**：物种沸点/熔点（1 atm 查表）+ 容器温度/压力 → 相态（气/液/固/溶液）；沸腾蒸发、冷凝液化、凝固结晶。
- **玩家交互**：蒸馏塔把氨水加热分馏（塔底水、塔顶氨）；冷凝段接冷却；蒸发结晶器浓缩。
- **边界**：相变=查表+按比例切换，不做连续两相平衡。
- **Create 对接**：**气体即流体**（全量 Forge Fluid 注册）；蒸发/冷凝的相变发生在釜内流股（自研）；储存/运输层无相变。
- **可表达**：查表规则，可表达。

## M4 浓度与溶解

- **定义**：溶液浓度 = 离子单位 / 水单位（**连续浓度**，见 03 §5）；溶解度曲线（温度分档查表）；过饱和→结晶；溶解/稀释为釜内反应（规则引擎）。
- **玩家交互**：浓/稀是**连续浓度**（离子/水比）不是物种；「浓硫酸稀释」是釜内反应（放热，禁忌，按浓度判定）；蒸发浓缩出晶体（item）。
- **边界**：溶解度=离散查表；不模拟摩尔浓度与活度。
- **前置概念（互溶性，见 [03-substance-model §5.4](03-substance-model.md)）**：「能溶解」分两问——液-液能否混溶（互溶性，决定能否形成同一杯溶液）是前置门槛；固体能溶多少（溶解度）是本机制。两者维度不同，互溶性先行。
- **Create 对接**：溶液=离子基底单一 mixture（模式别名，不逐种注册），Create 管道照常运输；结晶产物=item 走传送带。
- **可表达**：查表+配方，可表达。

## M5 反应引擎（核心）

- **定义**：白名单配方制；釜内流股模拟：反应进度（0→100%）、中间态（分步反应）、条件（温度窗口/压力下限/浓度下限/催化剂）、速率（基础速率×温度系数×搅拌系数×规模）、放热/吸热（ΔH 影响温度）、平衡简化（转化率上限/条件切换方向）。
- **玩家交互**：引擎**自动匹配**配方（原料/产物/条件见 JEI）；诊断状态（缺料/温度不满足/输出满/无配方）走护目镜 HUD 与指示灯；配催化剂（V₂O₅/铁触媒，寿命耐久）。
- **边界**：不做真实动力学；分步反应用配方链（中间态=中间产物物种，如 NaHCO₃、SO₃）；平衡只做「转化率上限+方向切换」。
- **Create 对接**：配方=ProcessingRecipe 派生（自定义 RecipeType `chemical_reaction`：item+fluid 输入、HeatCondition、processingTime、概率副产）；釜体执行端自研（流股模拟），但配方描述/注册/JEI/datagen/KubeJS 全白拿。
- **可表达**：配方数据+进度模拟，完全可表达。
- **运行模式**：分批式（进度 0→100% 一次性结算）与连续流（停留时间 τ=V/Q 分率转化、未反应出流）两档，见 [13-flow-modes.md](13-flow-modes.md)。

## M6 沉淀与悬浮

- **定义**：釜内浆料流股含悬浮固相（固含量）；沉淀池静置沉降；搅拌维持悬浮。
- **玩家交互**：碳化釜产出 NaHCO₃ 浆料 → 抽到沉淀池 → 底泥（浓浆）→ 过滤机。
- **边界**：固相不单独建模为粒子，只作为流股固含量字段+渲染底部层。
- **Create 对接**：浆料=高粘度 Forge Fluid 物种（石膏浆/重碱浆）可运输；沉降/过滤是釜/池/滤机的行为。
- **可表达**：字段+行为，可表达。

## M7 固液分离（过滤/离心/蒸馏/结晶）

- **定义**：过滤机（压滤/带滤）：浆料→滤液流体+滤饼 item；离心机：精细分离；蒸馏：按沸点分离；结晶：蒸发/冷却出晶体。
- **玩家交互**：滤饼上传送带运走；滤液回系统；蒸馏塔板数决定分离纯度。
- **边界**：过滤效率=配方参数（滤饼含水率）；蒸馏按沸点差查表，不做平衡级数模拟。
- **液-液分离（倾析/分相，D18 已落地）**：不互溶相在罐内按密度分层（`collapseIfNeeded` 按互溶组合并、气体独立相），与「按沸点分离」（蒸馏）、「按固液分离」（过滤）并列。抽哪一相由**端口**决定——**底口=重相先出**（普通抽出，D18 `drain(int)` 密度序）；**顶口=轻相先出**（分液）。
  - **分液软管（转化式，D18.5）**：把 **Create 软管滑轮**装到**开口釜正上方**（软管从开口顶伸入），放置时经 Forge `BlockEvent.EntityPlaceEvent`（浅 hook，非深 mixin）**特化为自研「分液软管」块**——换方块 ID、继承 `HorizontalKineticBlock`、保留 `HORIZONTAL_FACING`。JEI/创造栏仍只有原版软管滑轮一个；敲掉/中键拾取掉回原版（`getCloneItemStack` + loot 表指向 `create:hose_pulley`）。
  - **软管跟随虚拟液面**：BE 沿 DOWN 找下方开口釜，`offset`（`LerpedFloat`）追釜的 `getFillHeight()`（fill/容量），液面降软管跟着降；抽液走釜的 `drainLightest(...)`（`drain(int)` 反向排序）。
  - **扳手双模式（锁相）**：默认「**只抽上层**」= 软管记住当前抽的那一相 identity（`FluidStack.isFluidEqual`），该相抽空即停、不落回下一相（正确处理「两层→上层抽空→变一层」）；「**全部抽**」= 不锁相、密度序排空。扳手（`WrenchItem`）右键循环，护目镜 HUD（`IHaveGoggleInformation`）显示模式，无 GUI。
  - **触发/反馈/发现性**：特化瞬间加「咬合」粒子/音效（同成型成功），不静默换 ID；Ponder/JEI 信息页说清「软管滑轮装在开口釜上 = 分液软管」。
  - **分液口（已实现，底口）**：`decant_port` 是 `vessel_walls` 壁块（非凸出、可接管），其 `FLUID_HANDLER` 只暴露最重相——锁相（首次出料锁最重相、抽干即停，浮球阀语义）；普通管道接砖 = 排空（重相先出）。顶口撇轻相仍走软管滑轮。
- **Create 对接**：滤饼/晶体=item（漏斗/传送带/机械臂全通）；蒸馏塔=模板实例（再沸釜+塔板+冷凝段）。
- **可表达**：可表达。

## M8 换热与热回收

- **定义**：换热器让两股流体交换热量；回收放热反应/冷凝热给进料预热。
- **玩家交互**：接触法 SO₂ 预热进料；合成氨废热→锅炉给水预热；冷却塔排热（低品位热丢弃）。
- **边界**：换热=两流股温度交换（热量守恒近似，效率参数）；不做传热系数模拟。
- **Create 对接**：换热器=自研管道块（M13）；夹套接口接釜。
- **可表达**：可表达。

## M9 管网输运（双轨）

- **定义**：液体/气体/浆料全部走 Create 管道（Forge Fluid 网络，单流体/网，混液炸管）；釜内流股不外出；固体走传送带。
- **玩家交互**：Create 机械泵增压；阀门分流；喷头灌装；混液事故（炸管）教育「分类输送」。
- **边界**：管道无温度/压力属性（标准态运输）；高温/高压只在釜内（经夹套/流股接口处理）。
- **互溶性 × 管网（见 [03 §5.4](03-substance-model.md)）**：互溶性决定「能否共线输送」——互溶流体进罐先合并成单一 `mixture` 流体，管道看到一个流体，安全；不互溶流体共管 = 两个不同流体 = **触发混液炸管（D17）**。罐内抽出按相密度先后（互溶相 = 单一混合流体；不互溶相 = 各相独立先后抽出，非混合）。
- **Create 对接**：管道/泵/阀/喷头全复用；**炸管=禁忌混合事故的物理表现（D17）**。
- **可表达**：可表达；「热流体运输」限制为设计约束（热物料就近加工，不长途泵送——符合直觉）。

## M10 危险与事故

- **定义**：超压爆炸、热失控、禁忌混合（浓硫酸+水）、腐蚀漏液、堵塞；事故强度可配置（仅损物料/破坏结构）。
- **玩家交互**：装泄压阀/报警仪表/隔离阀；读手册警告；扑救（泼水降温？→ 又是禁忌教学）。
- **边界**：事故=事件表驱动（条件→效果），不做连锁物理模拟（但可配置连锁）。
- **Create 对接**：混液炸管原生（D17）；爆炸用通用 API+领地保护；其他事故自研事件。
- **可表达**：事件表，可表达。

## 汇总：机制 → 载体/对接表

| 机制 | 载体 | Create 对接点 | 自研量 |
|------|------|--------------|--------|
| M1 温度 | 釜内流股温度 + 热级 | HeatLevel/HeatCondition/BoilerHeater | 中（夹套/电热器） |
| M2 压力 | 釜内压力字段 + 密封等级 | 无 | 高（泄压/爆炸） |
| M3 相态 | 物种沸点/熔点查表 | 气体=流体注册 | 中 |
| M4 浓度 | 连续浓度（离子/水比）+ 溶解度查表 | mixture 浓度域（D19） | 低 |
| M5 反应 | 釜内流股模拟 | ProcessingRecipe 派生 | 高（核心） |
| M6 沉淀 | 流股固含量 + 沉降行为 | 浆料=流体 | 中 |
| M7 分离 | 滤机/离心/蒸馏行为 | 产物=item 走物流 | 中 |
| M8 换热 | 换热器流股交换 | 无（自研块） | 中 |
| M9 管网 | Create 管道 + 传送带 | 全复用 | 低 |
| M10 事故 | 事件表 | 混液炸管/爆炸 API | 中 |
