# 01 · 游戏性总纲

## 1. 玩家实际在做什么

核心循环不是背化学式，而是工程改造：

```text
获得原料 → 选择结构 → 布置内部件和端口 → 接动力/热/物流
→ 启动并观察 → 诊断瓶颈 → 回收副产物 → 扩建与闭环
```

玩家第一次运行可以粗糙、低效甚至需要人工取样；自动化、稳定性和回收率来自后续建设，而不是更高级的同功能方块直接替换。

## 2. 五个乐趣支柱

### 2.1 搭建

同一种结构通过布局承担不同用途。玩家看到的是自己的工程方案，而不是固定模型机器。

### 2.2 驯服

温度、压力、流量、浓度、搅拌、气氛和停留时间产生可预期后果。玩家从“能反应”逐步做到“稳定运行”。

### 2.3 分离

真正的难点经常是从混合物中拿到产品：沉降、过滤、洗涤、分液、结晶、蒸馏和炉渣分层应与反应同等重要。

### 2.4 闭环

尾气、母液、炉气、废热、滤渣和未反应物不是垃圾标签，而是需要管线回收的物质流。闭环必须降低长期原料或能源成本。

### 2.5 放大

放大不是容量乘法。大釜改变热惯性，大塔增加有效级数，大池增加允许表面负荷，大炉提高料层与热回收潜力，同时引入新的控制问题。

## 3. 产品用途契约

一条产业进入主线前，至少满足两项：

- 产物是另一条主线的必要原料；
- 产物大量消耗于建筑、物流、农业、采矿、能源或维护；
- 副产物可回收为有价值资源；
- 工艺解锁一种新的工程操作；
- 与 Create 既有产线形成明确增益或替代路线。

只用于“收藏化学品”的产物属于扩展内容，不得占据主线开发优先级。

## 4. 信息与控制

- 常态信息来自世界内仪表、试纸、护目镜、声音、粒子、液面、料层和 Display Link。
- 不提供配方选择列表；输入与条件决定过程。
- 不提供中央 GUI 数字控制台；连续物理量由热源、转速、泵速、阀和换热面积决定。
- 阈值和节拍使用 Create 风格滚动设置、比较器和红石链接。
- 化验级信息可以是昂贵工具或开发模式，不把平衡求解器内部值无条件展示给玩家。

## 5. 失败设计

失败分三层：

1. **偏离**：转化下降、夹带、混合盐渣、欠烧、产品不纯。
2. **软故障**：堵塞、停机、泄漏、催化剂失活、炉衬损耗、损失部分物料。
3. **事故**：超压、热失控、危险混合、熔体外泄；只有持续无视预警或硬核配置才破坏结构。

服务端提供 `OFF / SOFT / FULL` 事故强度。所有事故必须有提前可见、可自动联锁的信号。

## 6. 教学方式

每种新拓扑只用一条垂直切片教学：

- 釜：盐水精制、石膏沉淀与分散吸收，教投料、搅拌、通气、终点和过滤。
- 池：连续浆料澄清，教面积负荷、浊度和排泥。
- 炉：石灰煅烧，教温度、固体流、炉气回收和欠烧。

教程使用 Ponder 蓝图展示“推荐配置”，明确这不是唯一造法。

## 7. 终局

终局不是合成一个最终物品，而是让多个工艺区稳定协同：

- 原料利用率提高；
- 废水和尾气达标；
- 炉气、废热和未反应物回收；
- 产品纯度和吞吐达到目标；
- 玩家能从显示板和厂区状态判断问题。

可选挑战包括零外排、最小占地、最低能耗、最大稳定吞吐和特定产品纯度，不把单一“100% 回收率”写死为唯一胜利条件。
