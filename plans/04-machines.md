# 04 · 机器与方块清单（Create 架构版）

> 文档状态：**current**（方块清单，含 S11–S15 节拍控制件）

> 依据生态盘点与平台决策（00-ecosystem-recon §0），本文件重写 v1 机器清单。
> **核心变化**：机器从「17 种各自独立的多方块」改为「**1 个自研多方块模板（反应容器）→ 实例化出多种化工容器** + 少量专用功能块 + 大量复用 Create 方块」。自研方块从 ~70 降到 ~30。

---

## 1. 总览：三层结构

```
┌─ 运输/储存层（全部复用 Create，零自研）────────────────────┐
│  流体管道/泵/阀、FluidTank 多方块储罐、喷头/排水口、传送带/漏斗 │
│  所有 61 种化学物种 = Forge Fluid，罐内组合（匠魂式）处理简单混合 │
├─ 反应层（自研：模板 + 功能块）─────────────────────────────┤
│  【模板】反应容器：釜/塔/池 三种形状实例 × 密封等级 × 尺寸       │
│  【功能块】搅拌头、压缩机、换热器、电解槽、过滤机、离心机、      │
│           冷却塔、回转窑、塔板、喷淋/填料、加热器（高温）        │
│  釜内 = 流股模拟（反应进度、中间态、温度、压力、浓度、催化）      │
├─ 辅助层（自研小件 + 复用）─────────────────────────────────┤
│  仪表（温度/压力/浓度/液位）、泄压阀、催化剂托盘、批次程控器、          │
│  罐装化学品物品；电力 = createaddition 电网，热源 = Blaze      │
│  Burner/锅炉/液体烈焰人，控制 = 红石/转速控制器                │
└──────────────────────────────────────────────────────────┘
```

## 2. 自研多方块模板：反应容器（范本）

**一个模板，三个形状实例，参数化**（详细结构规范见 [10-multiblock.md](10-multiblock.md)）：

| 参数 | 取值 |
|------|------|
| 形状 | **釜式**（3×3 底 × 高 2–6，圆角）/ **塔式**（1×1~3×3 底 × 高 3–12）/ **池式**（3×3~7×7 底 × 高 1） |
| 密封等级 | 常压（T1）→ 密封（T2）→ 高压 ≤20 MPa（T3，需耐压内衬） |
| 搅拌 | 无 / 搅拌头（kinetic）/ 鼓泡（气体注入） |
| 热接口 | 底部热源槽位（Blaze Burner 等，走 HeatCondition）或 夹套口（接换热器/蒸汽） |
| 流体口 | 液体口 × N（Forge Fluid 进出）+ 气体口 × M（气体流体进出） |
| 内部件 | 塔板（塔式）、喷淋/填料（吸收塔）、催化剂托盘、排汽口、出渣口 |

**模板实例化清单**（就是原 v1 的 17 台机器，现在大部分是同一模板的配置差异）：

| ID | 名称 | 形状×密封 | 关键配置 | 解锁 |
|----|------|----------|---------|------|
| M02 | 反应釜 | 釜式×常压→密封 | 搅拌头 + 热接口，通用反应 | T1 |
| M03 | 高压釜 | 釜式×高压 | 耐压内衬 + 压缩机供压，合成氨/拜耳溶出 | T3 |
| M04 | 蒸馏塔 | 塔式×密封 | 塔板 + 底部再沸釜 + 塔顶冷凝，多组分分离 | T2 |
| M05 | 吸收塔 | 塔式×常压 | 喷淋头 + 填料，气液吸收（NH₃/HCl/SO₂） | T2 |
| M06 | 沉淀池 | 池式×常压 | 无搅拌，沉降固相（浆料→清液+底泥） | T1 |
| M07 | 中和池 | 池式×常压 | 搅拌头，酸碱中和（放热需冷却接口） | T1 |
| M08 | 终点结晶器（✅ U17 已实现，反应釜子类 `CrystallizerControllerBlockEntity`） | 釜式×常压 | 热接口（继承烈焰人热级）+ 开口排汽 + **冷凝回收**（通气量累加→内置馏出罐，被动外推）；**物理量终点控制**（°Bé 设定点世界内滚动，到点 `heatTarget` 切热）；终点强充能 15 + 比较器 °Bé 进度（模拟红石接 S04 同源读数）；机器无物种知识——「只析 A 不析 B」由设定点低于 B 饱和线挣得（见 03 §6 测量诚实性）；设定点由玩家挣取：校准运行（浊度初浑记波美度）/ JEI 溶解度手册推算 / 试纸质检；分馏切馏分=终点后排空由外部红石执行（S12 排空触发） | T2 |
| M15 | 尾气净化塔 | 塔式×常压 | 喷淋 + 药剂槽 + Create Fan 引风 | T3 |
| M16 | 煅烧炉（竖窑） | 塔式×常压 | 高温热源 + 连续进出料（funnel/传送带），石灰窑 | T1/T2 |

## 4. 复用清单（零自研，直接依赖）

| 需求 | 复用 Create/创想方块 |
|------|---------------------|
| 储罐 | **FluidTank 多方块**（3×3×高 32，无框架）——全部标准态液体/气体流体 |

## 5. 辅助单方块（自研小件，S 系列）

| ID | 名称 | 功能 |
|----|------|------|
| S01 | ~~控制面板~~（已取消） | 釜无 GUI：状态=护目镜 HUD + 贴面仪表（S02–S04）；物品=釜内世界渲染（Create Basin 模式，可开口釜顶观察）+ 漏斗/管道存取；控制=物理装置（热源/冷却）。依据 AGENTS.md 设计基调 |

| S11 | 液位计 | 贴面读容器总液量/各相液位；红石阈值 + 比较器模拟信号（流体阈值开关） |
| S12 | 反应状态接口 | 把 `ReactorStatus` 与进度映射为红石/比较器；「反应完成」=批式排空触发 |
| S13 | 计量投料口 | 红石脉冲定量注入 N mB（批式投料） |
| S14 | 溢流口 | 连续模式被动液位自稳（物理堰，CSTR 式） |
| S15 | 批次程控器 | 四相节拍器（投料→反应→排空→复位），相时长滚动调值，红石输出 |

| S17 | 浊度计（✅ U17 已实现，双形式） | 读悬浮域含量（4 档：清/微浑/浑/浆，边界 1%/5%/20%，沉底床不计）；沉淀型终点 + 初浑报警止损。详见 [12-instruments.md](12-instruments.md) |
| S18 | 电导率计（✅ U16.5 已实现，双形式） | 读离子强度（对数分箱）；洗涤终点（滤液电导不再降）+ U10 去离子水验收。详见 [12-instruments.md](12-instruments.md) |

> 节拍控制注记（原 13-flow-modes §1/§2/§5–§7 要点）：控制链 = **测量（S02–S04/S11/S12/S16–S18）→ 决策（原版红石 + Create 阈值开关/红石链接/Sequenced Gearshift）→ 执行（Smart Fluid Pipe/机械泵/Clutch 离合）**，零 GUI。批式四相触发信号：S13 定量投料 → S11 满检测启动 → S12 完成触发排空 → S11 空检测 + 定时复位；连续流由 S14 溢流堰被动自稳（无需红石）。批式/连续流的引擎语义（τ=V/Q 停留时间模型）见 [06-reaction-system.md](06-reaction-system.md) §10。**S15 不是 GUI 编程面板**：它把玩家可手搓的红石时序**打包**，相时长世界内滚动调值，外部红石完全互通——手搓与程控并存。可视化复用显示板 + Display Link。**仪表族统一红石双输出规范（比较器模拟分箱 + ValueSettings 阈值强充能，可切高于/低于）见 [12-instruments.md](12-instruments.md) §3。**
