## 1. 总览：三层结构

```
┌─ 运输/储存层（全部复用 Create，零自研）────────────────────┐
│  流体管道/泵/阀、FluidTank 多方块储罐、喷头/排水口、传送带/漏斗 │

├─ 反应层（自研：模板 + 功能块）─────────────────────────────┤

└──────────────────────────────────────────────────────────┘
```

## 2. 自研多方块模板：反应容器（范本）

**一个模板，三个形状实例，参数化**（详细结构规范见 §8）：

| 参数 | 取值 |
|------|------|
| 形状 | **釜式**（3×3 底 × 高 2–6，圆角）/ **塔式**（1×1~3×3 底 × 高 3–12）/ **池式**（3×3~7×7 底 × 高 1） |
| 密封等级 | 常压（T1）→ 密封（T2）→ 高压 ≤20 MPa（T3，需耐压内衬） |
| 搅拌 | 无 / 搅拌头（kinetic）/ 鼓泡（气体注入） |
| 热接口 | 底部热源槽位（Blaze Burner 等，走 HeatCondition）或 夹套口（接换热器/蒸汽） |
| 流体口 | 液体口 × N（Forge Fluid 进出）+ 气体口 × M（气体流体进出） |
| 内部件 | 塔板（塔式）、喷淋/填料（吸收塔）、催化剂托盘、排汽口、出渣口 |

**模板实例化清单**（就是原 v1 的 17 台机器，现在大部分是同一模板的配置差异）：

## 8. 多方块模板规范（原 10-multiblock 活段并入，2026-08）

> 与 Create FluidTank 的分工：运输与储存用 Create 罐（单种流体）；发生反应用自研容器（多物种流股 + 温度/压力/进度）。玩家心智：罐是仓库，釜是反应器。成型/绑定/酒漏/能力代理的实现已抽入 `vessel/` 基类（U3），本节收录规格活段。

### 8.1 结构组成与尺寸

```
        ┌── 顶盖（密封件，可选排气口/加料口）──┐
        │   内部件：搅拌头 / 塔板 / 喷淋 / 催化剂托盘 │
        │   控制器（一面，无 GUI，状态走护目镜 HUD）       │
  ┌─────┼─────┐  壳体（环壁） 窗口（观察/量具）   │
  │ 端口  │  端口 端口=流体口(液/气)、热接口、   │
  │(旋转口)│       (旋转口=搅拌轴穿过)         │
  └─────┴───┬─┘  底（热源槽位/排渣口）          │
            └── 内衬（耐腐蚀/耐压/保温，可选）    │
```

| 部件 | 方块 | 功能 |
|------|------|------|
| 壳体 | 化工砖/钢壳/合金壳（3 材质） | 结构主体；材质决定基础耐温/耐压（下表） |
| 内衬 | 耐酸衬/耐压衬/保温衬（2–3 种） | 叠加属性：腐蚀耐受、压力上限、隔热 |
| 窗口 | 观察窗（化工玻璃） | 透光、液位/温度色 |
| 端口 | 液体口、气体口、旋转口、热接口（4 种） | 与外部体系对接（下表） |
| 控制器 | 釜/塔/池控制器 | 成型校验、状态机、护目镜 HUD/诊断、红石输出 |
| 底/顶 | 底板（热源槽位）、顶盖（密封/排汽/加料） | 形状与密封相关 |

尺寸限制（防滥用+性能；现行为任意 W×W×H 3..7，见 progress 已知限制）：

| 形状 | 底面 | 高度 |
|------|------|------|
| 釜式 | 3×3（圆角壳） | 2–6 |
| 塔式 | 1×1 ~ 3×3 | 3–12 |
| 池式 | 3×3 ~ 7×7 | 1（可 2 层加深） |
| 高压釜 | 3×3（环形壁） | 2–4 |

成型哲学与 Create 罐同款：先搭后激活，控制器右键校验（形状/材质一致/无缺口/端口未堵），成型后结构为整体，破坏任一部件 → 整体失效（内部流体保留 NBT，重建可恢复，破口分级酒漏见 progress 修复记录）。

### 8.2 材质分级（耐温/耐压/耐腐蚀表）

| 材质 | 解锁 | 耐温 | 耐压 | 耐腐蚀 | 说明 |
|------|------|------|------|--------|------|
| 化工砖（陶/砖+涂层） | T1 | ≤200°C | 常压 | 弱酸弱碱 | 入门 |
| 钢壳 | T2 | ≤600°C | 密封 3 MPa | 一般 | 氯碱/硫酸主材 |
| 耐压合金壳+耐压衬 | T3 | ≤1000°C | 高压 20 MPa | 强酸 | 合成氨/拜耳法 |
| 耐酸衬（铅/玻璃衬） | T2 | 同壳体 | 同壳体 | 浓酸/浓碱 | 硫酸/氯碱设备 |

组合规则：**壳体决定基础，内衬叠加属性**（如钢壳+耐压衬 = 高压；钢壳+耐酸衬 = 强酸釜）。属性不足的反应配方直接拒绝执行（提示缺什么）。

### 8.4 故障与安全（事故 D17）

| 故障 | 触发 | 表现 | 预防 |
|------|------|------|------|
| 超压 | 密封容器内气体量×温度超限 | 先漏气（顶盖缝隙喷气）→ 泄压阀排放 → 未装阀则**爆炸**（破坏结构，范围按容量） | S05 泄压阀、压力表报警、配方限压 |
| 热失控 | 放热反应 + 冷却不足 → 温度超限 | 温度飙升动画 + 反应加速（正反馈）→ 超温分解/爆炸 | 冷却接口、换热器、配方温度窗口 |
| 禁忌混合 | 釜内出现禁忌组合（浓硫酸+水等） | 剧烈反应事故（产热+产气+腐蚀） | 规则引擎检测（03 §13.2 安全网）、手册警告、仪表报警 |
| 腐蚀 | 强腐蚀流体 + 无耐酸内衬 | 内衬/壳体耐久下降 → 漏液 | 材质分级表提示 |
| 堵塞 | 浆料固含量过高 + 无搅拌/沉淀池 | 出料口堵塞，泵空转 | 过滤机、搅拌、浓度控制 |

### 8.5 扩展方式与性能（后续自研多方块的范本）

新容器 = 复制模板参数表，不写新结构逻辑：选形状/尺寸/密封组合 → 注册新控制器（复用 vessel/ 结构校验与状态机）→ 挂内部件（新需求新做 1 个内部件方块）→ 注册配方集 + 配色。性能：低频结算（配方 10 tick/温度 5 tick/压力 20 tick，大釜降频）；同 chunk 多容器共享结算调度器（已预留）；结构+内容全量 NBT，区块卸载整体序列化。

## 9. 读数仪器体系（原 12-instruments 全文并入，2026-08）

> 本文是读数仪器的**唯一定义**——新增/修改仪器先改本节，再落到 §5/§7 的 S 系列清单与 11 的单元序列。上游原则：[03 §6](03-substance-model.md)（测量诚实性）、AGENTS.md 设计基调（世界内仪表/GUI 弱化）。单元挂钩：U17（主体）、U16.5（电导率计）、U10（去离子水验收）。

### 9.0 一句话结论

**连续贴面仪表封顶 7 台**（温度计/压力表已实现 + 波美计/pH 计/浊度计/电导率计/液位计）**+ 消耗性试纸族**，不再多。每台仪表 = 读数函数 + 量程 + 分箱 + 阈值行为，照 S03 模式复制，边际成本递减。

### 9.1 设计原则

1. **测量诚实性**（03 §6）：玩家仪器只读**物理间接量**——pH、密度、浊度、电导率、温度、压力、液位、颜色。引擎内部知识（SI/speciation/成分百分比）永远不可见，仅 `Chemistry.ASSAY` dev 化验模式解锁。
2. **机器不替玩家化验**：无纯度阈值判定、无「物种识别」输出——「是什么」永远是化学活（试纸/焰色/投料行为）；机器只回答「多少/到没到」。
3. **终点类型学（仪表封顶的依据）**：无机化工的「反应完了没」只有四类信号物理量，每类恰好一台化学仪表：
   | 终点类型 | 典型场合 | 仪表 |
   |---|---|---|
   | 化学势（滴定型） | 中和、碳化、吸收 | pH 计 |
   | 质量浓度（浓缩型） | 酸碱浓度、盐水饱和 | 波美计 |
   | 相态（沉淀型） | 除杂「刚不再浑」、初浑报警 | 浊度计 |
   | 离子强度（洗涤/纯水型） | 洗滤饼、去离子水验收 | 电导率计 |
   新产线先问「终点属于哪一类」，四类里选，**不再新增仪表类型**。
4. **世界内交互**（AGENTS 基调）：读数=贴面指针/刻度 + 护目镜行；阈值=ValueSettings 世界内滚动调值；零 GUI。

用法（已实现）：对**反应釜控制器或任意壁面仪表/化工砖**右键蘸取 → 消耗 1 张 → 动作栏变色反馈；结果键 `paper.chemicaladdon.*`。早期便宜、一次性；对应连续仪表是进阶替代（试纸→pH 计的升级曲线）。

**获取设计（定案 2026-08，未实现）：全部试纸保底走奖励箱/流通，化学自产为后期通道**——
- **指示剂族（石蕊/酚酞/广泛 pH）**：有机染料（D15 出圈），不可能化学合成。
- **离子检验族（AgNO₃/BaCl₂/KSCN）**：奖励箱是**保底而非唯一**——前期没产线时保证有纸可用（检验工具不能锁在它服务的产线后面，鸡生蛋）；试剂无机可产（Ag+HNO₃ 红氧已解禁、BaCO₃+HCl、NH₄SCN+KOH），**后期自产通道保留**（C1 收编 silver_metal/NH₄SCN 物种后 datagen 灌装配方：试剂溶液+纸→试纸，Create 灌装机/部署器）——与「酚酞捡的→pH 计造的」同构：同一检测需求，前期靠捡、后期靠自己，loot 只在前期不可替代。
- **流通渠道**：结构箱/遗迹箱成品 + 流浪商人（药剂师人设）出售作保底再生；离子族后期化学自产（见上）。检测工具获取梯度：试纸（捡/买保底，化学可自产）→ 滤光镜（原版玻璃+Create 造）→ 连续仪表（化学产线）。指示剂族永久依赖流通（有机出圈，无法自产——捡的终点）。

**滤光片焰色镜族（设计占位，2026-08，未实现）**：焰色检验扩展为「多镜联判」——元素焰色是离散调色板（Na 黄/K 紫/Ca 砖红/Cu 蓝绿/Ba 黄绿，[Sr 洋红待物种]），滤光镜按「吸收色带」定义，判断 = 组合消元；每面镜都是双刃剑（滤目标干扰色也误杀同色带元素，如钴镜滤 Na 黄同时误杀 Ba 黄绿→钕镜才是正道），玩家按怀疑顺序换镜 = 真实分析化学的排除法。封顶：元素 6–8、镜子 4–5，再多变色卡游戏。
- **获取原则（工具复杂度必须低于被测对象）**：镜片**不走化学合成**，走原版+Create——钴蓝镜=蓝染色玻璃+铁粒、绿镜=绿染色玻璃+铜粒、红镜=红染色玻璃+金粒（Create Mixing/Compacting 一步），钕镜（强吸黄进阶）=钴蓝镜+紫水晶（MC 语义稀土梗，可选）。理由：检验工具是玩化学的梯子第一级，锁在它服务的化工产线后面=鸡生蛋死锁（着色元素 Co/Ni/Cr 一个都没写进物种表，为镜子补全套采冶数据不成比例）；镜子用原版玻璃系反哺原版物料循环，而非自成孤岛。检测工具四层梯度：试纸（捡）→ 滤光镜（原版造）→ 离子试纸（化学挣）→ 连续仪表（工业化）。
- **诚实性红线**：镜子可以不化学，**被测对象不行**——Sr/Li 若入焰色表必须走完整化学（新物种/矿石），不为镜色发明化学。

### 9.3 红石联动（仪表族铁律，统一双输出）

1. **比较器模拟量 0–15**：量程内分箱，给红石算术电路用。
2. **阈值模式（自动化主力）**：ValueSettingsBehaviour 世界内滚动设阈值 + 右键切「高于/低于触发」，满足时强充能 15。典型控制语义全是事件触发：pH ≥ 7 停投酸、波美 ≥ 25 停加热、初浑 → 断料、电导 ≤ 阈值 → 洗涤完成。
3. **pH 映射注记**：pH 是对数标尺，线性分箱 1 级 = 1 pH 语义天然正确；等当点附近一滴跳 3–5 个 pH → 红石跳变，窗口检测（「先过 4 再过 7」）用原版比较器即可搭。
4. **为何阈值模式是主力**：等当点跳变快于模拟量采样周期，事件语义比轮询 16 级稳；与 S12–S15 节拍链衔接：测量（仪表族）→ 决策（原版红石 + Create 阈值开关）→ 执行（Smart Fluid Pipe/泵/Clutch），零 GUI。

### 9.5 引擎依赖（读数函数的实现前置）

- **Kw 常数（U17 已实现，pH 计唯一前置）**：`Chemistry.KW = 1e-14`。酸性侧直读 H⁺；碱性侧 [H⁺] = Kw/[OH⁻]；中和定点两离子皆 0 → pH 7。**实现决策：Kw 落读数层常数而非求解器条目**——真实自电离对会写回 Ions 域、改变 GCD ratio-tag 身份（釜内已解液与同配比新装桶永不堆叠，且 1 unit 对除读数外一切机制不可见）。与弱电解质通道的中和交互 JUnit 复核通过（等当点 ±1 mB 跳 pH 11↔7↔3）。
- **波美换算（U17 已实现）**：浓度（Σ溶解 units / 水 units）→ °Bé 声明式线性换算，锚点=曲线饱和盐水——不分物种，同浓度不同盐波美几乎一样是特性不是缺陷（诚实性：告诉你溶了多少，不告诉你溶了什么）。
- **浊度/电导**：`Suspended` 域 / 离子域直读，零引擎改动。
- **护目镜行（U17 已实现）**：各表读数进 HUD；SI/speciation 行已降级 `ChemicalAddon.ASSAY_ON`。

### 9.6 与机器的关系（仪表不是装饰）

- **M08 终点结晶器**（✅ U17）：读同一物理量的执行器——°Bé 设定点世界内滚动 + 到点切热（`heatTarget` 覆写）+ 终点红石 + 排汽冷凝回收；「只析 A 不析 B」由设定点低于 B 饱和线挣得（设定点挣取三路径：校准运行/手册推算/试纸质检；精度来源是化学不是机器）。
- **过滤机洗水模式**（U16.5）：置换洗涤洗穿滤饼，S18 读滤液电导=洗涤终点闭环。
