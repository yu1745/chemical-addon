# 07 · 非模板设备与共用部件

## 1. 原则

不是所有工业设备都应成为多方块。独特性来自局部处理而非大型空间拓扑的设备，使用专用单方块、相邻扩容单元或 Create 原生装置。

## 2. 核心设备

### 2.1 过滤机

过滤机采用固定三格组合专机，不升级为第五种通用多方块模板：动力压紧端（保留 `filter_press` 注册 ID）→滤板组→管汇端。结构轴向由动力端朝向决定；动力端接 Create 旋转并由任意面输入浆料，滤板组任意面输入洗水并抽出滤饼，管汇端任意面输出滤液。端口语义按结构方块区分、不再按六面区分，三股流体仍不共享 capability 节点。浆料→滤液＋滤饼，支持母液夹带、置换洗涤和滤饼再浆。与池形成“沉降预浓缩→压滤脱水”，而不是互相替代。

活动表现复用 Create 的基础设施：动力端按 `HorizontalKineticBlock`/`KineticBlockEntity`，压紧动画采用 `PortableStorageInterfaceRenderer` 的六向伸缩变换与 `MechanicalPressRenderer` 的活动压头模式；使用本模组滤板 PartialModel，不引入机械活塞的 Contraption 移动系统。

### 2.2 电解槽

专用主体＋相邻电极/隔膜单元扩容，统一覆盖：

- 氯碱膜电解；
- 水电解；
- 金属电积与电解精炼；
- 未来熔盐电解。

配方声明电解质相态、电极/隔膜、FE、温度和产物端口。不同工业名称不注册不同槽体。

### 2.3 换热器与冷凝器

可串联管道模块，两股物料只交换能量不交换组成。必须显示进出口温度、传热瓶颈和累计回收热量，否则不会形成有意义的优化玩法。

### 2.4 压缩机与真空设备

Create 转速/FE→气体输送与容器压力条件。压力保持容器状态，不产生“高压气体”注册变体。真空泵复用同一设备的反向用途，需求成熟时开放。

### 2.5 固体前后处理

- 粉碎、研磨、洗矿、压制优先复用 Create。
- 筛分、浮选、造粒、喷雾干燥、铸造只有在至少三条重要工艺共享且产生独特控制时立项。
- 回转窑动态结构只可能是炉式的表现/升级，不成为新模板。

## 3. 内部件注册原则

内部件必须提供可复用能力标签，而非锁定一条配方。例如：

- `agitation`、`gas_dispersion`、`catalyst_bed`；
- `packing_stage`、`distillation_stage`、`demister`；
- `aeration`、`sludge_scraper`；
- `solid_grate`、`hot_blast`、`molten_hearth`、`electrode`。

一件只服务单条配方且不改变操作的内部件应合并成催化剂/材料条件，而不是新增方块。

## 4. 仪表与分析

现有温度、压力、pH、波美度、浊度、电导率和试纸继续构成基础分析层。新增读数按玩法需求引入：

| 读数 | 主要结构 | 用途 |
|---|---|---|
| 液位/相界面 | 釜、池、炉熔池 | 批次、溢流、分层抽取 |
| 流量 | 全部 | 连续流与物料平衡 |
| 塔顶尾气质量/压降 | 塔 | 吸收达标、液泛与堵塞 |
| 底泥/料层高度 | 池、炉 | 排泥、停留时间、堵塞 |
| 炉气 O₂/还原性（游戏化） | 炉 | 气氛控制 |

读数应尽量复用统一贴面仪表基类和 Display Link，不为每个结构复制显示系统。

## 5. 节拍与安全件

- 计量口、状态口、液位计和批次程控用于釜式批次。
- 溢流堰、流量计和回流阀用于连续过程。
- 泄压阀、爆破片、紧急冷却用于压力安全。
- 塔的旁路/回流、池的自动排泥、炉的燃料切断均使用普通红石互锁。

### 5.1 化工 PLC

复杂批次和连续过程使用相邻机架式 PLC。每个 I/O 模块六面独立配置输入、输出与
通道；单机架最多 64 个唯一通道、32 个持久寄存器。信号采用 live-zero：0 表示
断线/无效，模拟量 1–15，布尔量 1/15。PLC 每拍先快照输入、运行程序、再原子提交
输出；重复通道、多控制器、程序错误或看门狗超限时锁存故障并把输出归零。

同一控制器提供两种程序模式：64 条上限的传统指令表，以及内嵌 Rhino 的受限 JS。
指令表首版包含算术、比较、布尔、限幅、映射、迟滞、通电延时、脉冲、上升沿、
置位/复位和条件跳转；256 步看门狗阻止死循环。
JS 只获得输入、输出、寄存器、计时器、边沿和故障 API，不可访问 Java、世界、文件
或网络；每拍未写的输出默认归零，跨重启状态必须显式放入 PLC 寄存器。

### 5.2 分析与特化检测

温度、压力、pH、波美度、电导率、浊度、液位、流量、固体料层与真实 pe/ORP 是
通用过程量，量程由世界内滚轮设置并输出 1–15 模拟量，不再各自承担报警比较。
过程状态发送器输出设备状态，取代旧状态口。

试纸检测箱是游戏化的单目标分析仪：奖励试纸决定目标、液/气相、信号类型和线性/
对数刻度，玩家设置上下量程。普通目标输出浓度模拟量；石蕊输出酸/中/碱枚举，
酚酞输出开关量，亚铁/铁及硝酸根/亚硝酸根组合纸输出低/中/高枚举。它直接读取
目标浓度而不模拟共存干扰；这是为了
避免为每个特殊终点制造永久仪表的明确简化。手持试纸可重复使用但只给定性结果，
`/ca assay` 仍是唯一能查看完整精确组成与数量的入口。

## 6. 复用 Create 的边界

优先使用 Create 的管道、泵、阀、罐、传送带、漏斗、机械臂、风扇、动力网络、Display Link、Ponder 和 ProcessingRecipe。自研只覆盖多组分状态、化学过程、相分离、结构能力和 Create 没有的工业端口。

## 7. 完成标准

每个新增专用设备必须回答：为什么不能用四种模板或 Create 原件表达、至少服务哪些流程、玩家控制什么、失败如何反馈、如何自动化。答不出来则不立项。
